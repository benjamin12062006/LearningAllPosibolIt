## Objetivo de la lección

Agrupar los conteos de los todos en un ObjectType propio, AggregationsType, devuelto por una sola query `aggregations`, y marcar como obsoleto un campo que repite otro con `deprecationReason`.

## Estado inicial heredado

Clase 42: TodoService guarda los todos en memoria y expone getters totalTodos, pendingTodos y completedTodos; TodoResolver tiene tres queries sueltas que los devuelven como Int.

## Fase 1 — Un ObjectType para los conteos

**Objetivo:** Un ObjectType para los conteos.

**Código o cambio acumulativo:**

```text
import { Field, Int, ObjectType } from '@nestjs/graphql';

@ObjectType({ description: 'Todo quick aggregations' })
export class AggregationsType {
  @Field(() => Int)
  total: number;

  @Field(() => Int)
  pending: number;

  @Field(() => Int)
  completed: number;
}
```


**Por qué:** En lugar de varias queries sueltas, un objeto agrupa los conteos en un nivel propio de la respuesta. Sin Int, GraphQL tomaría number como Float.

**Cómo comprobarlo y resultado esperado:** El esquema muestra el tipo AggregationsType con tres campos Int no nulos.

**Procedencia:** E3 / E4 / E5 / E6.

## Fase 2 — Query que devuelve el objeto

**Objetivo:** Query que devuelve el objeto.

**Código o cambio acumulativo:**

```text
@Query(() => AggregationsType)
aggregations(): AggregationsType {
  return {
    completed: this.todoService.completedTodos,
    pending: this.todoService.pendingTodos,
    total: this.todoService.totalTodos,
  };
}
```


**Por qué:** El cliente pide solo los campos que necesita dentro del mismo objeto.

**Cómo comprobarlo y resultado esperado:** aggregations { total pending } devuelve los conteos actuales.

**Procedencia:** E1 / E2 / E7 / E8.

## Fase 3 — Marcar un campo como obsoleto

**Objetivo:** Marcar un campo como obsoleto.

**Código o cambio acumulativo:**

```text
@Field(() => Int, { deprecationReason: 'Must use completed instead' })
totalTodosCompleted: number;
```


**Por qué:** Un campo que repite otro no se borra de golpe: se marca obsoleto con el motivo y la alternativa, y las herramientas lo avisan.

**Cómo comprobarlo y resultado esperado:** El explorador muestra el campo tachado y el motivo.

**Procedencia:** E9 / E10.

# Resumen mental

Un ObjectType propio agrupa datos derivados en un nivel de la respuesta. Un campo que sobra se marca obsoleto con deprecationReason en lugar de borrarlo.
