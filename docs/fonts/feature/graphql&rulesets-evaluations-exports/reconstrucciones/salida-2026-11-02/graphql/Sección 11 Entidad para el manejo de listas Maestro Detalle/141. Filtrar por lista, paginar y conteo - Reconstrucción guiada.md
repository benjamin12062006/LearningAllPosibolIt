## Objetivo de la lección

Filtrar el detalle por su maestro, paginarlo y contarlo: `items` recibe la lista padre, PaginationArgs y SearchArgs y usa un query builder por `listId`; un segundo @ResolveField `totalItems` cuenta los items de esa lista.

## Estado inicial heredado

Clase 139: ListsResolver.getListItems(@Parent list) devuelve todos los ListItem con repository.find(); ItemsService.findAll(user, pagination, search) de la clase 125 ya construye un query builder paginado.

## Fase 1 — Argumentos del campo items

**Objetivo:** Argumentos del campo items.

**Código o cambio acumulativo:**

```text
@ResolveField(() => [ListItem], { name: 'items' })
async getListItems(
  @Parent() list: List,
  @Args() paginationArgs: PaginationArgs,
  @Args() searchArgs: SearchArgs,
): Promise<ListItem[]> {
  return this.listItemService.findAll(list, paginationArgs, searchArgs);
}
```


**Por qué:** Con el padre, el servicio sabe de qué lista son los items; con los argumentos, el cliente decide cuántos y desde dónde.

**Cómo comprobarlo y resultado esperado:** lists { name items(limit: 1) { quantity } } devuelve solo items de cada lista.

**Procedencia:** E1 / E2 / E3.

## Fase 2 — Consulta filtrada por el maestro

**Objetivo:** Consulta filtrada por el maestro.

**Código o cambio acumulativo:**

```text
async findAll(
  list: List,
  paginationArgs: PaginationArgs,
  searchArgs: SearchArgs,
): Promise<ListItem[]> {
  const { limit, offset } = paginationArgs;
  const { search } = searchArgs;

  const queryBuilder = this.listItemsRepository
    .createQueryBuilder()
    .take(limit)
    .skip(offset)
    .where(`"listId" = :listId`, { listId: list.id });

  if (search) {
    queryBuilder.andWhere('LOWER(name) like :name', {
      name: `%${search.toLowerCase()}%`,
    });
  }

  return queryBuilder.getMany();
}
```


**Por qué:** Es la consulta paginada de ItemsService con el repositorio de ListItem y el filtro por listId en lugar de userId.

**Cómo comprobarlo y resultado esperado:** Cada lista muestra solo sus items.

**Procedencia:** E4 / E5 / E6 / E7 / E8.
