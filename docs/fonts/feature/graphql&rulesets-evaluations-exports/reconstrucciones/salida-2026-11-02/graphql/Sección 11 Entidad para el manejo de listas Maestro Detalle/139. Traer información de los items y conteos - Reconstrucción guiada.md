## Objetivo de la lección

Que una lista exponga su detalle como un campo `items` resuelto por el resolver de la lista: quitar el @Field de la relación, añadir un @ResolveField que recibe la lista con @Parent e inyectar ListItemService importando su módulo.

## Estado inicial heredado

Lista (List) con relación @OneToMany a ListItem expuesta con @Field; ListItemModule exporta ListItemService y TypeOrmModule; ListsResolver solo inyecta ListsService. La estructura de las entidades viene de las clases 135–138, no consultadas: los nombres de la relación se toman de la transcripción.

## Fase 1 — Quitar la relación directa del esquema

**Objetivo:** Quitar la relación directa del esquema.

**Código o cambio acumulativo:**

```text
@OneToMany(() => ListItem, (listItem) => listItem.list)
// @Field(() => [ListItem])
listItem: ListItem[];
```


**Por qué:** La relación devolvería todos los items sin paginar y con un nombre poco claro; sin @Field deja de consultarse directamente.

**Cómo comprobarlo y resultado esperado:** lists { listItem { id } } falla: el campo ya no existe.

**Procedencia:** E1 / E2.

## Fase 2 — Campo items resuelto con el padre

**Objetivo:** Campo items resuelto con el padre.

**Código o cambio acumulativo:**

```text
@ResolveField(() => [ListItem], { name: 'items' })
async getListItems(@Parent() list: List): Promise<ListItem[]> {
  return this.listItemService.findAll();
}
```


**Por qué:** Cada lista resuelve su campo items; @Parent da la lista que se está recorriendo. El nombre se fija para no exponer getListItems.

**Cómo comprobarlo y resultado esperado:** lists { name items { id quantity completed } } responde (todavía con todos los items).

**Procedencia:** E3 / E4 / E5 / E6 / E10.

## Fase 3 — Inyectar el servicio del detalle

**Objetivo:** Inyectar el servicio del detalle.

**Código o cambio acumulativo:**

```text
// lists.module.ts
imports: [TypeOrmModule.forFeature([List]), ListItemModule],

// lists.resolver.ts
constructor(
  private readonly listsService: ListsService,
  private readonly listItemService: ListItemService,
) {}
```


**Por qué:** Para usar ListItemService en el resolver de listas, su módulo debe exportarlo y ListsModule importarlo; ponerlo en exports da el error de Nest que se ve en la clase.

**Cómo comprobarlo y resultado esperado:** La aplicación arranca sin el error de proveedor no encontrado.

**Procedencia:** E7 / E8 / E9.
