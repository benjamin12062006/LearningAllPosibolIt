## Objetivo de la lección

Distinguir una función pura (misma entrada → misma salida, sin efectos sobre elementos externos) de una que no lo es, en C#: sacar la fecha actual fuera de la función recibiéndola por parámetro y devolver un objeto nuevo en lugar de modificar el recibido por referencia.

## Estado inicial heredado

Solución del curso con proyectos anteriores. Se añade un proyecto de consola nuevo FunctionalProgramming; la versión de .NET es indiferente según el instructor.

## Fase 1 — Función no pura por depender del reloj

**Objetivo:** Función no pura por depender del reloj.

**Código o cambio acumulativo:**

```csharp
Console.WriteLine(Tomorrow());
Console.ReadLine();
Console.WriteLine(Tomorrow());

DateTime Tomorrow() => DateTime.Now.AddDays(1);
```


**Por qué:** Sin parámetros, la entrada es siempre la misma, pero el resultado cambia con la hora: viola el determinismo.

**Cómo comprobarlo y resultado esperado:** Las dos líneas impresas difieren en minutos/segundos.

**Procedencia:** E1 / E2 / E3 / E4.

## Fase 2 — Recibir el tiempo como parámetro

**Objetivo:** Recibir el tiempo como parámetro.

**Código o cambio acumulativo:**

```csharp
Console.WriteLine(TomorrowPure(new DateTime(2024, 1, 1, 12, 0, 0)));

DateTime TomorrowPure(DateTime time) => time.AddDays(1);
```


**Por qué:** La función deja de decidir qué día es hoy; quien la llama lo aporta y la salida solo depende de la entrada.

**Cómo comprobarlo y resultado esperado:** Con la misma fecha, el resultado es igual en cualquier ejecución.

**Procedencia:** E5 / E6 / E10.

## Fase 3 — Efecto colateral al modificar un objeto

**Objetivo:** Efecto colateral al modificar un objeto.

**Código o cambio acumulativo:**

```csharp
var beer = new Beer() { Name = "Heineken" };
Console.WriteLine(ToUpper(beer).Name);
Console.WriteLine(beer.Name);

Beer ToUpper(Beer beer)
{
    beer.Name = beer.Name.ToUpper();
    return beer;
}
```


**Por qué:** Un objeto se pasa por referencia: cambiar beer.Name dentro cambia el objeto de fuera.

**Cómo comprobarlo y resultado esperado:** Ambas líneas muestran HEINEKEN.

**Procedencia:** E7 / E8.

## Fase 4 — Devolver un objeto nuevo

**Objetivo:** Devolver un objeto nuevo.

**Código o cambio acumulativo:**

```csharp
Beer ToUpperPure(Beer beer)
{
    var newBeer = new Beer() { Name = beer.Name.ToUpper() };
    return newBeer;
}
```


**Por qué:** La función produce su resultado sin tocar la entrada.

**Cómo comprobarlo y resultado esperado:** El resultado está en mayúsculas y el original conserva Heineken.

**Procedencia:** E9.

## FunctionalProgramming/Program.cs

Procedencia: E2 proyecto; E3–E6 fechas; E7–E9 cervezas; E10 explicación de struct. otherBeer y la fecha de ejemplo son ensamblados.

```csharp
// Programa de consola FunctionalProgramming (.NET, instrucciones de nivel superior).
// La ejecución va arriba; funciones y clases, debajo.

Console.WriteLine(Tomorrow());
Console.ReadLine();
Console.WriteLine(Tomorrow()); // valor distinto: no es pura

Console.WriteLine(TomorrowPure(new DateTime(2024, 1, 1, 12, 0, 0)));
Console.ReadLine();
Console.WriteLine(TomorrowPure(new DateTime(2024, 1, 1, 12, 0, 0))); // mismo valor

var beer = new Beer() { Name = "Heineken" };
Console.WriteLine(ToUpper(beer).Name);
Console.WriteLine(beer.Name); // también en mayúsculas: se modificó el original

var otherBeer = new Beer() { Name = "Heineken" };
Console.WriteLine(ToUpperPure(otherBeer).Name);
Console.WriteLine(otherBeer.Name); // sin cambios

// Funciones no puras
DateTime Tomorrow() => DateTime.Now.AddDays(1);

Beer ToUpper(Beer beer)
{
    beer.Name = beer.Name.ToUpper();
    return beer;
}

// Funciones puras
DateTime TomorrowPure(DateTime time) => time.AddDays(1);

Beer ToUpperPure(Beer beer)
{
    var newBeer = new Beer() { Name = beer.Name.ToUpper() };
    return newBeer;
}

class Beer
{
    public string Name { get; set; }
}
```

# Resumen mental

Pura = depende solo de sus parámetros y no cambia nada fuera. Lo variable (reloj) entra por parámetro; los objetos recibidos no se modifican: se devuelve uno nuevo. Eso hace la función repetible, fácil de probar y reutilizable.
