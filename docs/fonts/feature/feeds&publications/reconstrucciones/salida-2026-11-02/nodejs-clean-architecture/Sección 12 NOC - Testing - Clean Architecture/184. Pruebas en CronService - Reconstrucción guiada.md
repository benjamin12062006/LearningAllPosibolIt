## Objetivo de la lección

Probar el adaptador `CronService`: crear un trabajo que se dispara cada segundo con una función simulada (`jest.fn`), esperar dos segundos y comprobar que se llamó dos veces; detener el trabajo al terminar.

## Estado inicial heredado

`CronService.createJob(cronTime, onTick)` de la clase 112 crea, arranca y devuelve un `CronJob`.

## Fase 1 — Test con función simulada y espera real

**Objetivo:** Test con función simulada y espera real.

**Código o cambio acumulativo:**

```text
import { CronService } from './cron-service';

describe('CronService', () => {
  const mockTick = jest.fn();

  test('should create a job', (done) => {
    const job = CronService.createJob('* * * * * *', mockTick);

    setTimeout(() => {
      expect(mockTick).toBeCalledTimes(2);
      job.stop();
      done();
    }, 2000);
  });
});
```


**Por qué:** Lo que se prueba es que el adaptador entrega a la librería el horario y la tarea; la función simulada cuenta las llamadas. Sin job.stop() el trabajo seguiría vivo tras el test.

**Cómo comprobarlo y resultado esperado:** El test pasa con 2 y falla si se espera 3.

**Procedencia:** E1 / E2 / E3 / E4 / E5 / E6 / E7 / E8 / E9 / E10.

# Resumen mental

Un programador de tareas se prueba por su contrato (qué ejecuta y con qué horario), no por la librería. Cualquier trabajo creado en una prueba se detiene al final.
