## Objetivo de la lección

Añadir a la aplicación Nest un módulo para Sam Assistant y comprobar sus dos primeras rutas con un DTO para la pregunta.

## Fase 3 — Exponer dos operaciones

**Objetivo:** Montar createThread y userQuestion para comprobar el flujo de HTTP.

**Código o cambio acumulativo:**

```typescript
import { Body, Controller, Post } from '@nestjs/common';
import { QuestionDto } from './dto/question.dto';
import { SamAssistantService } from './sam-assistant.service';

@Controller('sam-assistant')
export class SamAssistantController {
  constructor(private readonly samAssistantService: SamAssistantService) {}

  @Post('create-thread')
  async createThread() {
    return 'createThread';
  }

  @Post('user-question')
  async userQuestion(@Body() questionDto: QuestionDto) {
    return questionDto;
  }
}
```


**Por qué:** La creación del hilo puede iniciarse sin cuerpo. La pregunta recibe QuestionDto en @Body.

**Cómo comprobarlo y resultado esperado:** En Postman, llamar a POST /sam-assistant/create-thread y luego a POST /sam-assistant/user-question con threadId y question. La primera ruta devuelve su texto provisional y la segunda devuelve los campos enviados.

**Procedencia:** E2 / E3 / E5 / E6.
