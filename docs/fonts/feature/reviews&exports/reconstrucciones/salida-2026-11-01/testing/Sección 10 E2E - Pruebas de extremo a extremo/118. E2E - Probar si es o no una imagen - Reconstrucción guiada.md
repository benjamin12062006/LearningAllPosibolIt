## Objetivo de la lección

Completar las pruebas E2E del módulo de archivos con Supertest: rechazar un archivo que no es imagen, subir una imagen real y comprobar la respuesta y el archivo creado en disco, borrarlo al terminar y pedir una imagen inexistente.

## Fase 1 — Rechazar un archivo que no es imagen

**Objetivo:** Rechazar un archivo que no es imagen.

**Código o cambio acumulativo:**

```text
it('should throw a 400 error if file selected is not an image', async () => {
  const response = await request(app.getHttpServer())
    .post('/files/product')
    .attach('file', Buffer.from('This is a test file'), 'test.txt');

  expect(response.status).toBe(400);
  expect(response.body).toEqual({
    message: 'Make sure that the file is an image',
    error: 'Bad Request',
    statusCode: 400,
  });
});
```


**Por qué:** Un archivo multipart se adjunta con attach, no con send. Un Buffer permite probar el rechazo sin tener un archivo real.

**Cómo comprobarlo y resultado esperado:** La prueba pasa con el fileFilter actual.

**Procedencia:** E3 / E4 / E5 / E6.

## Fase 2 — Subir una imagen real y comprobar propiedades

**Objetivo:** Subir una imagen real y comprobar propiedades.

**Código o cambio acumulativo:**

```text
const testImagePath = join(__dirname, 'test-image.jpg');

it('should upload image file successfully', async () => {
  const response = await request(app.getHttpServer())
    .post('/files/product')
    .attach('file', testImagePath);

  const fileName = response.body.fileName;

  expect(response.status).toBe(201);
  expect(response.body).toHaveProperty('secureUrl');
  expect(response.body).toHaveProperty('fileName');
  expect(response.body.secureUrl).toContain('/product');
});
```


**Por qué:** El nombre lo genera el servidor (UUID), así que no se puede comparar el objeto completo: se comprueban las propiedades y una parte estable de la URL.

**Cómo comprobarlo y resultado esperado:** La prueba pasa, pero cada ejecución deja una imagen nueva en static/products.

**Procedencia:** E7 / E8 / E9 / E10 / E11 / E12 / E13 / E14.

## Fase 3 — Comprobar el archivo en disco y borrarlo

**Objetivo:** Comprobar el archivo en disco y borrarlo.

**Código o cambio acumulativo:**

```text
const filePath = join(__dirname, '../../../static/products', fileName);
const fileExists = existsSync(filePath);

expect(fileExists).toBe(true);

unlinkSync(filePath);
```


**Por qué:** La prueba verifica que el archivo existe donde debe y lo elimina para no dejar basura entre ejecuciones.

**Cómo comprobarlo y resultado esperado:** Tras ejecutar las pruebas, static/products no tiene archivos nuevos.

**Procedencia:** E15 / E16 / E19.

## Fase 4 — Pedir una imagen inexistente

**Objetivo:** Pedir una imagen inexistente.

**Código o cambio acumulativo:**

```text
it('should throw a 400 error if the requested image does not exist', async () => {
  const imageName = 'no-product-image.jpg';

  const response = await request(app.getHttpServer()).get(
    `/files/product/${imageName}`,
  );

  expect(response.status).toBe(400);
  expect(response.body).toEqual({
    message: `No product found with image ${imageName}`,
    error: 'Bad Request',
    statusCode: 400,
  });
});
```


**Por qué:** Cubre la rama del servicio que comprueba la existencia sin revelar la ruta.

**Cómo comprobarlo y resultado esperado:** La prueba pasa con el mensaje del servicio.

**Procedencia:** E17 / E18.

## test/files/file-upload.e2e-spec.ts

Procedencia: E1–E19. Preparación (beforeAll/afterAll, opciones del pipe) y ruta de AppModule ensambladas a partir de la clase 117 y de los «tres directorios atrás» de E15; forma del cuerpo de error inferida.

```ts
import { INestApplication, ValidationPipe } from '@nestjs/common';
import { Test, TestingModule } from '@nestjs/testing';
import { existsSync, unlinkSync } from 'fs';
import { join } from 'path';
import * as request from 'supertest';
import { AppModule } from '../../../src/app.module';

describe('FilesModule (e2e)', () => {
  let app: INestApplication;
  const testImagePath = join(__dirname, 'test-image.jpg');

  beforeAll(async () => {
    const moduleFixture: TestingModule = await Test.createTestingModule({
      imports: [AppModule],
    }).compile();

    app = moduleFixture.createNestApplication();
    // Opciones copiadas del E2E anterior; no se muestran en esta clase.
    app.useGlobalPipes(new ValidationPipe());
    await app.init();
  });

  afterAll(async () => {
    await app.close();
  });

  it('should throw a 400 error if no file selected', async () => {
    const response = await request(app.getHttpServer()).post('/files/product');

    expect(response.status).toBe(400);
    expect(response.body).toEqual({
      message: 'Make sure that the file is an image',
      error: 'Bad Request',
      statusCode: 400,
    });
  });

  it('should throw a 400 error if file selected is not an image', async () => {
    const response = await request(app.getHttpServer())
      .post('/files/product')
      .attach('file', Buffer.from('This is a test file'), 'test.txt');

    expect(response.status).toBe(400);
    expect(response.body).toEqual({
      message: 'Make sure that the file is an image',
      error: 'Bad Request',
      statusCode: 400,
    });
  });

  it('should upload image file successfully', async () => {
    const response = await request(app.getHttpServer())
      .post('/files/product')
      .attach('file', testImagePath);

    const fileName = response.body.fileName;

    expect(response.status).toBe(201);
    expect(response.body).toHaveProperty('secureUrl');
    expect(response.body).toHaveProperty('fileName');
    expect(response.body.secureUrl).toContain('/product');

    const filePath = join(__dirname, '../../../static/products', fileName);
    const fileExists = existsSync(filePath);

    expect(fileExists).toBe(true);

    unlinkSync(filePath);
  });

  it('should throw a 400 error if the requested image does not exist', async () => {
    const imageName = 'no-product-image.jpg';

    const response = await request(app.getHttpServer()).get(
      `/files/product/${imageName}`,
    );

    expect(response.status).toBe(400);
    expect(response.body).toEqual({
      message: `No product found with image ${imageName}`,
      error: 'Bad Request',
      statusCode: 400,
    });
  });
});
```

# Resumen mental

Una prueba E2E con archivos adjunta contenido real o ficticio, comprueba lo que no cambia entre ejecuciones (propiedades, fragmentos de URL) y verifica el efecto en disco. Si crea archivos, los borra.
