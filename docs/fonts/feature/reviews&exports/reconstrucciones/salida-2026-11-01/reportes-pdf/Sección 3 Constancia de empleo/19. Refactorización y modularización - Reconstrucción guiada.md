## Objetivo de la lección

Extraer la impresora a un PrinterModule con un PrinterService exportado y reutilizable, inyectarlo en BasicReportsService y mover la definición del documento a funciones puras en src/reports que reciben opciones.

## Estado inicial heredado

Estado de la clase 18: BasicReportsService crea la impresora, la definición y el documento dentro de hello(); el controlador fija Content-Type, hace pipe y end.

## Fase 1 — Generar PrinterModule y PrinterService

**Objetivo:** Generar PrinterModule y PrinterService.

**Código o cambio acumulativo:**

```bash
nest g module printer
nest g service printer --no-spec
```


**Por qué:** Si la impresora vive en un servicio de reportes, cada módulo nuevo que imprima tendría que copiarla.

**Cómo comprobarlo y resultado esperado:** Existen src/printer/printer.module.ts y printer.service.ts, y AppModule importa PrinterModule.

**Procedencia:** E1 / E2 / E3.

## Fase 2 — Configurar la impresora una sola vez

**Objetivo:** Configurar la impresora una sola vez.

**Código o cambio acumulativo:**

```text
@Injectable()
export class PrinterService {
  private printer = new PdfPrinter(fonts);

  createPdf(
    docDefinition: TDocumentDefinitions,
    options: BufferOptions = {},
  ): PDFKit.PDFDocument {
    return this.printer.createPdfKitDocument(docDefinition, options);
  }
}
```


**Por qué:** La impresora es privada y ya viene configurada; los consumidores solo piden un documento. Un cambio de configuración afecta a todos.

**Cómo comprobarlo y resultado esperado:** Compila con los tipos de pdfmake.

**Procedencia:** E4 / E5 / E6 / E7 / E8 / E9.

## Fase 3 — Exportar, importar e inyectar

**Objetivo:** Exportar, importar e inyectar.

**Código o cambio acumulativo:**

```text
// printer.module.ts
@Module({
  providers: [PrinterService],
  exports: [PrinterService],
})
export class PrinterModule {}

// basic-reports.module.ts
imports: [PrinterModule],

// basic-reports.service.ts
constructor(private readonly printerService: PrinterService) {
  super();
}
```


**Por qué:** Un módulo solo ofrece lo que exporta. El servicio de reportes extiende PrismaClient y por eso llama a super().

**Cómo comprobarlo y resultado esperado:** La aplicación arranca sin errores de inyección.

**Procedencia:** E10 / E11 / E12.

## Fase 4 — Definiciones como funciones en src/reports

**Objetivo:** Definiciones como funciones en src/reports.

**Código o cambio acumulativo:**

```text
interface ReportOptions {
  name: string;
}

export const getHelloWorldReport = (
  options: ReportOptions,
): TDocumentDefinitions => {
  const { name } = options;

  const docDefinition: TDocumentDefinitions = {
    content: [`Hola ${name}`],
  };

  return docDefinition;
};
```


**Por qué:** Cada reporte es una función que recibe datos y devuelve la definición; el servicio la pasa a la impresora.

**Cómo comprobarlo y resultado esperado:** El GET devuelve un PDF con «Hola Fernando Herrera».

**Procedencia:** E13 / E14 / E15 / E16 / E17 / E18.

## src/printer/printer.service.ts

Procedencia: E5–E9; fuentes movidas desde la clase 18.

```ts
import { Injectable } from '@nestjs/common';
import PdfPrinter from 'pdfmake';
import type { BufferOptions, TDocumentDefinitions } from 'pdfmake/interfaces';

const fonts = {
  Roboto: {
    normal: 'fonts/Roboto-Regular.ttf',
    bold: 'fonts/Roboto-Medium.ttf',
    italics: 'fonts/Roboto-Italic.ttf',
    bolditalics: 'fonts/Roboto-MediumItalic.ttf',
  },
};

@Injectable()
export class PrinterService {
  private printer = new PdfPrinter(fonts);

  createPdf(
    docDefinition: TDocumentDefinitions,
    options: BufferOptions = {},
  ): PDFKit.PDFDocument {
    return this.printer.createPdfKitDocument(docDefinition, options);
  }
}
```

```ts
import { Injectable } from '@nestjs/common';
import { PrismaClient } from '@prisma/client';
import { PrinterService } from '../printer/printer.service';
import { getHelloWorldReport } from '../reports';

@Injectable()
export class BasicReportsService extends PrismaClient {
  constructor(private readonly printerService: PrinterService) {
    super();
  }

  // Miembros heredados de clases anteriores, no reconstruidos.

  hello() {
    const docDefinition = getHelloWorldReport({ name: 'Fernando Herrera' });

    const doc = this.printerService.createPdf(docDefinition);

    return doc;
  }
}
```

# Resumen mental

Lo reutilizable (la impresora configurada) va a un módulo que lo exporta; cada consumidor importa el módulo e inyecta el servicio. El contenido de cada documento es una función que recibe datos y devuelve una definición, sin conocer la impresora ni HTTP.
