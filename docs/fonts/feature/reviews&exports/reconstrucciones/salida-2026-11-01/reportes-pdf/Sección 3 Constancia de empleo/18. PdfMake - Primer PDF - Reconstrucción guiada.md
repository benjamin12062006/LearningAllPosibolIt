## Objetivo de la lección

Generar un PDF en el momento de la petición con pdfmake y enviarlo como respuesta: el servicio crea el documento a partir de una definición y el controlador fija Content-Type, encadena el documento a la respuesta con pipe y lo cierra con end().

## Estado inicial heredado

Proyecto Nest del curso con un módulo basic-reports cuyo controlador expone un GET que llama a BasicReportsService.hello(). Según la clase 19 (l. 31), el servicio extiende PrismaClient. El contenido previo de esos archivos no se muestra en esta clase ni en la 17 y no se reconstruye.

## Fase 1 — Instalar pdfmake y declarar las fuentes

**Objetivo:** Instalar pdfmake y declarar las fuentes.

**Código o cambio acumulativo:**

```bash
npm install pdfmake
npm install --save-dev @types/pdfmake

# Copiar Roboto-Regular.ttf, Roboto-Medium.ttf, Roboto-Italic.ttf
# y Roboto-MediumItalic.ttf en ./fonts (raíz del proyecto)
```


**Por qué:** pdfmake necesita conocer los archivos de cada variante de fuente antes de crear la impresora.

**Cómo comprobarlo y resultado esperado:** La carpeta fonts existe en la raíz con los cuatro archivos.

**Procedencia:** E1 / E2 / E3 / E4 / E5.

## Fase 2 — Crear el documento en el servicio

**Objetivo:** Crear el documento en el servicio.

**Código o cambio acumulativo:**

```text
import PdfPrinter from 'pdfmake';
import type { TDocumentDefinitions } from 'pdfmake/interfaces';

const fonts = {
  Roboto: {
    normal: 'fonts/Roboto-Regular.ttf',
    bold: 'fonts/Roboto-Medium.ttf',
    italics: 'fonts/Roboto-Italic.ttf',
    bolditalics: 'fonts/Roboto-MediumItalic.ttf',
  },
};

// TODO: Esto será optimizado después
hello() {
  const printer = new PdfPrinter(fonts);

  const docDefinition: TDocumentDefinitions = {
    content: 'Hola Mundo',
  };

  const doc = printer.createPdfKitDocument(docDefinition);

  return doc;
}
```


**Por qué:** El servicio solo construye el documento a partir de una definición; no sabe nada de HTTP.

**Cómo comprobarlo y resultado esperado:** Compila sin errores de tipos una vez instalados los tipos.

**Procedencia:** E6 / E7 / E10.

## Fase 3 — Enviar el documento desde el controlador

**Objetivo:** Enviar el documento desde el controlador.

**Código o cambio acumulativo:**

```text
@Get()
hello(@Res() response: Response) {
  const pdfDoc = this.basicReportsService.hello();

  response.setHeader('Content-Type', 'application/pdf');
  pdfDoc.info.Title = 'Hola-Mundo.pdf';
  pdfDoc.pipe(response);
  pdfDoc.end();
}
```


**Por qué:** El controlador decide cómo viaja el resultado: cabecera del tipo de contenido, flujo hacia la respuesta y cierre del documento.

**Cómo comprobarlo y resultado esperado:** En Insomnia, el GET devuelve un PDF con «Hola Mundo».

**Procedencia:** E8 / E9 / E11 / E13.

## Fase 4 — Permitir el import por defecto

**Objetivo:** Permitir el import por defecto.

**Código o cambio acumulativo:**

```json
{
  "compilerOptions": {

  }

```


**Por qué:** Sin esModuleInterop, el import por defecto de pdfmake falla con «is not a constructor».

**Cómo comprobarlo y resultado esperado:** El GET deja de responder 500.

**Procedencia:** E12.

## src/basic-reports/basic-reports.controller.ts

Procedencia: E8, E9, E11, E13; ruta 'basic-reports' y nombre del método ensamblados desde la petición «basic-report» citada en l. 43.

```ts
import { Controller, Get, Res } from '@nestjs/common';
import { Response } from 'express';
import { BasicReportsService } from './basic-reports.service';

@Controller('basic-reports')
export class BasicReportsController {
  constructor(private readonly basicReportsService: BasicReportsService) {}

  @Get()
  hello(@Res() response: Response) {
    const pdfDoc = this.basicReportsService.hello();

    response.setHeader('Content-Type', 'application/pdf');
    pdfDoc.info.Title = 'Hola-Mundo.pdf';
    pdfDoc.pipe(response);
    pdfDoc.end();
  }
}
```
