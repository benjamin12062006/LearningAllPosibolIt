## Objetivo de la lección

Crear la orden en OrdersService.create: confirmar los productos en el microservicio de productos, calcular el total con los precios de ese microservicio y no con los del cliente, contar los artículos y grabar la cabecera con una sola inserción de Prisma, dentro de un try/catch que responde un error genérico.

## Estado inicial heredado

Estado de la clase 71: OrdersService extiende PrismaClient, recibe por inyección productsClient (ClientProxy registrado con PRODUCT_SERVICE) y llama a firstValueFrom(this.productsClient.send({ cmd: 'validate_products' }, ids)) con ids fijos de prueba. CreateOrderDto tiene items con productId, quantity y price (clase 69).

## Fase 1 — Confirmar los productos dentro de try/catch

**Objetivo:** Confirmar los productos dentro de try/catch.

**Código o cambio acumulativo:**

```text
async create(createOrderDto: CreateOrderDto) {
  try {
    //1 Confirmar los ids de los productos
    const productIds = createOrderDto.items.map((item) => item.productId);
    const products: any[] = await firstValueFrom(
      this.productsClient.send({ cmd: 'validate_products' }, productIds),
    );
  } catch (error) {
    throw new RpcException({
      status: HttpStatus.BAD_REQUEST,
      message: 'Check logs',
    });
  }
}
```


**Por qué:** Si algún producto no existe, el microservicio de productos falla y la orden no se crea. El error público es genérico para no devolver más información de la necesaria.

**Cómo comprobarlo y resultado esperado:** Enviar un productId inexistente devuelve el error genérico.

**Procedencia:** E1 / E2 / E3 / E4 / E5 / E6 / E7.

## Fase 2 — Calcular con los precios de la fuente

**Objetivo:** Calcular con los precios de la fuente.

**Código o cambio acumulativo:**

```text
//2. Cálculos de los valores
const totalAmount = createOrderDto.items.reduce((acc, orderItem) => {
  const price = products.find(
    (product) => product.id === orderItem.productId,
  ).price;
  return price * orderItem.quantity;
}, 0);

const totalItems = createOrderDto.items.reduce((acc, orderItem) => {
  return acc + orderItem.quantity;
}, 0);
```


**Por qué:** El precio que llega del cliente o del gateway puede estar manipulado; se usa el que devuelve el microservicio de productos. Un mismo producto puede repetirse en items (otra talla o color), por eso se recorren los items y no los productos.

**Cómo comprobarlo y resultado esperado:** Con dos unidades de un producto, totalAmount es el doble de su precio en la base de productos.

**Procedencia:** E8 / E9 / E10 / E11.

## Fase 3 — Grabar la cabecera con una sola inserción

**Objetivo:** Grabar la cabecera con una sola inserción.

**Código o cambio acumulativo:**

```text
//3. Crear una transacción de base de datos
const order = await this.order.create({

    totalAmount: totalAmount,
```

**Por qué:** Cabecera e ítems están relacionados, así que una sola inserción anidada basta para que Prisma lo haga todo o nada; con tablas sin relación haría falta una transacción explícita.

**Cómo comprobarlo y resultado esperado:** La respuesta muestra la orden con totalAmount, totalItems y status PENDING, todavía sin ítems.

## src/orders/orders.service.ts

Procedencia: E1–E17; constructor, inyección y super() desde la clase 71 (l. 31–33); rutas de import de config y dto ensambladas.

```ts
import { HttpStatus, Inject, Injectable } from '@nestjs/common';
import { ClientProxy, RpcException } from '@nestjs/microservices';
import { PrismaClient } from '@prisma/client';
import { firstValueFrom } from 'rxjs';
import { PRODUCT_SERVICE } from 'src/config';
import { CreateOrderDto } from './dto';

@Injectable()
export class OrdersService extends PrismaClient {
  constructor(
    @Inject(PRODUCT_SERVICE) private readonly productsClient: ClientProxy,
  ) {
    super();
  }

  // Miembros heredados de clases anteriores, no reconstruidos.

  async create(createOrderDto: CreateOrderDto) {
    try {
      //1 Confirmar los ids de los productos
      const productIds = createOrderDto.items.map((item) => item.productId);
      const products: any[] = await firstValueFrom(
        this.productsClient.send({ cmd: 'validate_products' }, productIds),
      );

      //2. Cálculos de los valores
      const totalAmount = createOrderDto.items.reduce((acc, orderItem) => {
        const price = products.find(
          (product) => product.id === orderItem.productId,
        ).price;
        return price * orderItem.quantity;
      }, 0);

      const totalItems = createOrderDto.items.reduce((acc, orderItem) => {
        return acc + orderItem.quantity;
      }, 0);

      //3. Crear una transacción de base de datos
      const order = await this.order.create({
        data: {
          totalAmount: totalAmount,
          totalItems: totalItems,
        },
      });

      return order;
    } catch (error) {
      throw new RpcException({
        status: HttpStatus.BAD_REQUEST,
        message: 'Check logs',
      });
    }
  }
}
```

# Resumen mental

Los datos que deciden dinero salen de la fuente autorizada, no de lo que manda el cliente. Si cabecera y detalle están relacionados, una inserción anidada de Prisma los graba juntos o no graba nada.
