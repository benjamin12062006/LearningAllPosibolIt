## Objetivo de la lección

Conservar literales y restringir el array de roles con as const.

## Estado inicial heredado

Un array de roles sin as const se infiere como string[]. No se necesita código de otra lección.

## Fase 1 — Inferencia amplia

**Objetivo:** Inferencia amplia.

**Código o cambio acumulativo:**

```ts
const roles = ['admin', 'guest', 'editor'];
```


**Por qué:** Las propiedades de un array const aún admiten cambios; const restringe la reasignación de la variable.

**Cómo comprobarlo y resultado esperado:** Observar string[] en el editor; todavía se puede añadir otra cadena.

**Procedencia:** E1.

## Fase 2 — Inferencia estrecha

**Objetivo:** Inferencia estrecha.

**Código o cambio acumulativo:**

```ts
const roles = ['admin', 'guest', 'editor'] as const;
const firstRole = roles[0];
```


**Por qué:** as const conserva literales y prohíbe mutaciones desde TypeScript.

**Cómo comprobarlo y resultado esperado:** Observar readonly y el tipo literal admin; un push se rechaza al comprobar tipos.

**Procedencia:** E2 / E3.
