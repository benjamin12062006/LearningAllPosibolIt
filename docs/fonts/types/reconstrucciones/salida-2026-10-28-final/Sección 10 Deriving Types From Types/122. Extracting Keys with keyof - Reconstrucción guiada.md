## Fase 1 — Definir el objeto de tipos

**Objetivo:** Definir el objeto de tipos.

**Código o cambio acumulativo:**

```ts
type User = { name: string; age: number };
```


**Por qué:** El punto de partida es un tipo, no una variable de JavaScript.

**Cómo comprobarlo y resultado esperado:** Revisar sus dos nombres de propiedades y los tipos de sus valores.

**Procedencia:** E1.

## Fase 2 — Derivar las claves

**Objetivo:** Derivar las claves.

**Código o cambio acumulativo:**

```ts
type UserKeys = keyof User;
let validKey: UserKeys = 'age';
```


**Por qué:** keyof recibe User y devuelve los literales name y age.

**Cómo comprobarlo y resultado esperado:** El editor ofrece ambas claves y rechaza un tercer nombre.

**Procedencia:** E2.
