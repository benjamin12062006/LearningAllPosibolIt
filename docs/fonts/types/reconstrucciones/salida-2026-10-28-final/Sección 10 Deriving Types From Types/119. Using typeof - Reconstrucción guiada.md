## Objetivo de la lección

Distinguir typeof en ejecución y typeof en una declaración de tipo.

## Estado inicial heredado

La fuente declara un archivo typeof.ts nuevo y vacío.

## Fase 1 — Operador de JavaScript

**Objetivo:** Operador de JavaScript.

**Código o cambio acumulativo:**

```ts
const username = 'Max';
console.log(typeof username);
```


**Por qué:** typeof en una expresión produce el nombre del tipo durante la ejecución.

**Cómo comprobarlo y resultado esperado:** Al ejecutar el JavaScript compilado se espera string. Esta es una comprobación prevista del curso, no ejecutada aquí.

**Procedencia:** E1 / E2.

## Fase 2 — Operador en un alias

**Objetivo:** Operador en un alias.

**Código o cambio acumulativo:**

```ts
type Username = typeof username;
```


**Por qué:** El mismo token en posición de tipo deriva el tipo estático del valor existente.

**Cómo comprobarlo y resultado esperado:** El editor infiere el literal Max con const; si fuese let se ensancharía a string.

**Procedencia:** E3 / E4.

# Experimentos temporales y límites

Cambiar const por let es una comparación temporal. El alias desaparece en JavaScript y no sustituye la constante.
