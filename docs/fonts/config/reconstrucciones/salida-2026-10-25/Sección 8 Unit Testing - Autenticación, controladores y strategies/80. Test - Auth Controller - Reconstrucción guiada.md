## Fase 3 — Sustituir AuthService y recuperar el controlador

**Objetivo:** Sustituir AuthService y recuperar el controlador.

**Código o cambio acumulativo:**

```ts
const mockAuthService = {
  create: jest.fn(),
  login: jest.fn(),
  checkAuthStatus: jest.fn(), // cotejar identificador con el material original
};

const module: TestingModule = await Test.createTestingModule({
  imports: [PassportModule.register({ defaultStrategy: 'jwt' })],
  controllers: [AuthController],
  providers: [{ provide: AuthService, useValue: mockAuthService }],
}).compile();

const authController = module.get<AuthController>(AuthController);
expect(authController).toBeDefined();
```


**Por qué:** El token AuthService se resuelve al objeto controlado y se evita arrastrar UserRepository/JwtService. La aserción de esta clase comprueba el montaje; aún no comprueba llamadas a create/login ni respuestas HTTP.

**Cómo comprobarlo y resultado esperado:** Ejecutar el spec con Jest en la aplicación original debe permitir obtener el controlador y pasar should be defined. Antes de añadir casos sobre el tercer método, confirmar su nombre real. No se ejecutó esa comprobación al generar la guía.

```ts
import { Test, TestingModule } from '@nestjs/testing';
import { PassportModule } from '@nestjs/passport';
import { AuthController } from './auth.controller';
import { AuthService } from './auth.service';

const mockAuthService = {
  create: jest.fn(),
  login: jest.fn(),
  // La transcripción no recupera la grafía exacta de Checkstatus.
  checkAuthStatus: jest.fn(),
};

describe('AuthController', () => {
  let authController: AuthController;

  beforeEach(async () => {
    const module: TestingModule = await Test.createTestingModule({
      imports: [PassportModule.register({ defaultStrategy: 'jwt' })],
      controllers: [AuthController],
      providers: [
        { provide: AuthService, useValue: mockAuthService },
      ],
    }).compile();

    authController = module.get<AuthController>(AuthController);
  });

  it('should be defined', () => {
    expect(authController).toBeDefined();
  });
});
```

# Resumen mental

controllers contiene al sujeto; imports resuelve módulos del ejemplo; providers mapea el token AuthService al mock; compile construye el contenedor; module.get recupera la instancia. toBeDefined prueba montaje, no autorización, creación de usuarios ni login. Mantener esa diferencia evita atribuir seguridad a un test que solo inicializa dependencias.
