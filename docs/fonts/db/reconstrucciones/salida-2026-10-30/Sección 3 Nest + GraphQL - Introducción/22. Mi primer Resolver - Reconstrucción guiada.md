## Objetivo de la lección

Crear el primer módulo y resolver con un Query raíz helloWorld que devuelve String, ver el esquema generado y consultarlo en /graphql.

## Estado inicial heredado

AppModule con GraphQLModule.forRoot (ApolloDriver, autoSchemaFile) de la lección 21; la app no arranca por falta de Query raíz.

## Fase 1 — Crear el módulo y el resolver

**Objetivo:** Crear el módulo y el resolver.

**Código o cambio acumulativo:**

```bash
nest g mo helloWorld
nest g r helloWorld --no-spec
```


**Por qué:** El módulo agrupa la lógica de hola mundo; el resolver escucha las operaciones GraphQL de ese módulo.

**Cómo comprobarlo y resultado esperado:** AppModule importa HelloWorldModule y este registra HelloWorldResolver en providers.

**Procedencia:** E2 / E3 / E4.

## Fase 2 — Definir el Query raíz

**Objetivo:** Definir el Query raíz.

**Código o cambio acumulativo:**

```ts
import { Query, Resolver } from '@nestjs/graphql';

@Resolver()
export class HelloWorldResolver {
  @Query(() => String)
  helloWorld(): string {
    return 'Hola Mundo';
  }
}
```


**Por qué:** GraphQL necesita saber el tipo de retorno: el string de TypeScript no basta, se declara con () => String.

**Cómo comprobarlo y resultado esperado:** La app arranca y src/schema.gql contiene type Query { helloWorld: String! }.

**Procedencia:** E1 / E5 / E6 / E7.

## Fase 3 — Consultar en /graphql y desactivar el playground

**Objetivo:** Consultar en /graphql y desactivar el playground.

**Código o cambio acumulativo:**

```ts
GraphQLModule.forRoot<ApolloDriverConfig>({
  driver: ApolloDriver,
  playground: false,
  autoSchemaFile: join(process.cwd(), 'src/schema.gql'),
}),
```


**Por qué:** El playground documenta el esquema; puede quedar activo en desarrollo y desactivarse en producción.

**Cómo comprobarlo y resultado esperado:** En http://localhost:3000/graphql la consulta { helloWorld } devuelve el texto; con playground: false la página ya no muestra el playground.

**Procedencia:** E8 / E9.

## src/app.module.ts

Procedencia: Lección 21 (forRoot), E2, E9.

```ts
import { join } from 'path';
import { Module } from '@nestjs/common';
import { GraphQLModule } from '@nestjs/graphql';
import { ApolloDriver, ApolloDriverConfig } from '@nestjs/apollo';
import { HelloWorldModule } from './hello-world/hello-world.module';

@Module({
  imports: [
    GraphQLModule.forRoot<ApolloDriverConfig>({
      driver: ApolloDriver,
      playground: false,
      autoSchemaFile: join(process.cwd(), 'src/schema.gql'),
    }),
    HelloWorldModule,
  ],
  controllers: [],
  providers: [],
})
export class AppModule {}
```

# Resumen mental

Resolver ≈ controlador, pero va en providers. @Query de @nestjs/graphql + tipo GraphQL explícito → el esquema se regenera solo → /graphql responde.
