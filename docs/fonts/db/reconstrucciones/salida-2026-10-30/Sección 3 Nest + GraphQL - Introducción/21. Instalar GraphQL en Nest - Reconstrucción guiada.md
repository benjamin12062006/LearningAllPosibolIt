## Objetivo de la lección

Instalar los paquetes de GraphQL para Nest sobre Express, registrar GraphQLModule.forRoot con el driver de Apollo y generar el esquema automáticamente (code first).

## Estado inicial heredado

Proyecto Nest nuevo (02-todo) creado en la lección 20: se borraron AppController, AppService y su spec, AppModule quedó vacío y se desinstalaron los paquetes de Prettier/ESLint para no recibir avisos del linter.

## Fase 1 — Instalar las dependencias de GraphQL

**Objetivo:** Instalar las dependencias de GraphQL.

**Código o cambio acumulativo:**

```bash
yarn add @nestjs/graphql @nestjs/apollo graphql apollo-server-express
```


**Por qué:** Nest usa Express por defecto; estos paquetes integran GraphQL con el driver de Apollo sobre Express.

**Cómo comprobarlo y resultado esperado:** Los cuatro paquetes aparecen en package.json.

**Procedencia:** E1.

## Fase 2 — Registrar GraphQLModule con el driver de Apollo

**Objetivo:** Registrar GraphQLModule con el driver de Apollo.

**Código o cambio acumulativo:**

```ts
import { GraphQLModule } from '@nestjs/graphql';
import { ApolloDriver, ApolloDriverConfig } from '@nestjs/apollo';

// dentro de @Module({ imports: [...] })
GraphQLModule.forRoot<ApolloDriverConfig>({
  driver: ApolloDriver,
}),
```


**Por qué:** forRoot es la configuración raíz única de GraphQL; las features adicionales usarían forFeature.

**Cómo comprobarlo y resultado esperado:** Al guardar, la terminal muestra el error de Apollo que exige al menos un esquema (E4).

**Procedencia:** E2 / E3 / E4.

## Fase 3 — Generar el esquema automáticamente (code first)

**Objetivo:** Generar el esquema automáticamente (code first).

**Código o cambio acumulativo:**

```ts
import { join } from 'path';

GraphQLModule.forRoot<ApolloDriverConfig>({
  driver: ApolloDriver,
  autoSchemaFile: join(process.cwd(), 'src/schema.gql'),
}),
```


**Por qué:** Con code first el esquema schema.gql se genera desde clases y decoradores TypeScript; join viene de path de Node.

**Cómo comprobarlo y resultado esperado:** Todavía no compila: falta un Query raíz. Se resuelve en la lección 22.

**Procedencia:** E5 / E6 / E7.

## src/app.module.ts

Procedencia: E8 (módulo vacío), E3 (driver), E5 (autoSchemaFile).

```ts
import { join } from 'path';
import { Module } from '@nestjs/common';
import { GraphQLModule } from '@nestjs/graphql';
import { ApolloDriver, ApolloDriverConfig } from '@nestjs/apollo';

@Module({
  imports: [
    GraphQLModule.forRoot<ApolloDriverConfig>({
      driver: ApolloDriver,
      autoSchemaFile: join(process.cwd(), 'src/schema.gql'),
    }),
  ],
  controllers: [],
  providers: [],
})
export class AppModule {}
```

# Resumen mental

GraphQL en Nest = paquetes + GraphQLModule.forRoot(driver) + un esquema. En code first el esquema sale de las clases; sin al menos un Query raíz Apollo no arranca.
