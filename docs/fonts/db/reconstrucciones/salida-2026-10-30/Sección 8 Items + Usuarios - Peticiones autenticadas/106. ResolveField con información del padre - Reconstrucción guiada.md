## Objetivo de la lección

Añadir al tipo User un campo calculado itemCount con @ResolveField, usando @Parent para saber qué usuario se está resolviendo y contando sus items desde ItemsService.

## Estado inicial heredado

UsersResolver protegido con roles; ItemsService con findAll por usuario (lección 102); User e Item relacionados.

## Fase 1 — Declarar el campo calculado

**Objetivo:** Declarar el campo calculado.

**Código o cambio acumulativo:**

```ts
@ResolveField(() => Int, { name: 'itemCount' })
async itemCount(): Promise<number> {
  return 10;
}
```


**Por qué:** Un campo resuelto amplía el esquema sin tocar la entidad ni la base.

**Cómo comprobarlo y resultado esperado:** users { fullName itemCount } devuelve 10 para todos.

**Procedencia:** E1 / E2 / E3.

## Fase 5 — Usar el servicio y proteger con rol

**Objetivo:** Usar el servicio y proteger con rol.

**Código o cambio acumulativo:**

```ts
async itemCount(
  @CurrentUser([ValidRoles.admin]) adminUser: User,
  @Parent() user: User,
): Promise<number> {
  return this.itemsService.itemCountByUser(user);
}
```


**Por qué:** El campo hereda la protección del resolver y además exige rol admin.

**Cómo comprobarlo y resultado esperado:** Cada usuario muestra su conteo real; si no se pide itemCount no hay consulta SQL; también funciona al pedir item { user { itemCount } }.

**Procedencia:** E9 / E10.

## src/users/users.resolver.ts (fragmento)

Procedencia: E2–E4, E8, E9.

```ts
import { UseGuards } from '@nestjs/common';
import { Int, Parent, ResolveField, Resolver } from '@nestjs/graphql';
import { UsersService } from './users.service';
import { User } from './entities/user.entity';
import { ItemsService } from '../items/items.service';
import { JwtAuthGuard } from '../auth/guards/jwt-auth.guard';
import { CurrentUser } from '../auth/decorators/current-user.decorator';
import { ValidRoles } from '../auth/enums/valid-roles.enum';

@Resolver(() => User)
@UseGuards(JwtAuthGuard)
export class UsersResolver {
  constructor(
    private readonly usersService: UsersService,
    private readonly itemsService: ItemsService,
  ) {}

  // users, user, updateUser y blockUser (sección 7) sin cambios.

  @ResolveField(() => Int, { name: 'itemCount' })
  async itemCount(
    @CurrentUser([ValidRoles.admin]) adminUser: User,
    @Parent() user: User,
  ): Promise<number> {
    return this.itemsService.itemCountByUser(user);
  }
}
```
