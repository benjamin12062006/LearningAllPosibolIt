## Objetivo de la lección

Crear el módulo y resolver de Todo, exponer el Query todos y definir el tipo de objeto personalizado Todo con @ObjectType y @Field.

**Objetivo:** Generar módulo y resolver.

**Procedencia:** E1 / E2.

## Fase 2 — Primer Query todos con strings

**Objetivo:** Primer Query todos con strings.

**Código o cambio acumulativo:**

```ts
@Query(() => [String], { name: 'todos' })
findAll(): string[] {
  return ['a', 'b', 'c'];
}
```


**Por qué:** Paso intermedio para ver el Query en Apollo Studio y el error típico de importar Query de @nestjs/common.

**Cómo comprobarlo y resultado esperado:** En Apollo Studio aparece todos y devuelve ["a","b","c"].

**Procedencia:** E3 / E4 / E5.

## Fase 3 — Definir el ObjectType Todo

**Objetivo:** Definir el ObjectType Todo.

**Código o cambio acumulativo:**

```ts
import { Field, Int, ObjectType } from '@nestjs/graphql';

@ObjectType()
export class Todo {
  @Field(() => Int)
  id: number;

  @Field(() => String)
  description: string;

  @Field(() => Boolean)
  done: boolean = false;
}
```


**Por qué:** GraphQL solo conoce escalares; un tipo personalizado declara qué campos y tipos expone. Int se fija explícito para no inferir Float.

**Cómo comprobarlo y resultado esperado:** Tras guardar, el esquema incluye type Todo { id: Int!, description: String!, done: Boolean! }.

**Procedencia:** E6 / E7 / E8 / E9.

## Fase 4 — Devolver [Todo]

**Objetivo:** Devolver [Todo].

**Código o cambio acumulativo:**

```ts
@Query(() => [Todo], { name: 'todos' })
findAll(): Todo[] {
  return [];
}
```


**Por qué:** Si el Query declara [Todo] pero devuelve strings, GraphQL no puede resolver los subcampos y falla.

**Cómo comprobarlo y resultado esperado:** { todos { id description done } } responde [].

**Procedencia:** E10 / E11.

```ts
import { Field, Int, ObjectType } from '@nestjs/graphql';

@ObjectType()
export class Todo {
  @Field(() => Int)
  id: number;

  @Field(() => String)
  description: string;

  @Field(() => Boolean)
  done: boolean = false;
```
```ts
}
```

# Resumen mental

Resolver = punto de entrada; ObjectType + Field = contrato de salida. Un Query de objetos obliga al cliente a pedir subcampos.
