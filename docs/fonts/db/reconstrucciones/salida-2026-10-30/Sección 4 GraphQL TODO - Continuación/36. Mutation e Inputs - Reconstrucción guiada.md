## Objetivo de la lección

Declarar la primera Mutation (createTodo) y recibir su información mediante un InputType enviado como variable.

## Estado inicial heredado

TodoResolver con todos y todo (por ID) usando TodoService en memoria (lecciones 33–34).

## Fase 1 — Declarar la mutación

**Objetivo:** Declarar la mutación.

**Código o cambio acumulativo:**

```ts
@Mutation(() => Todo, { name: 'createTodo' })
createTodo() {}
```


**Por qué:** Query sirve para consultar y Mutation para modificar datos; ambas declaran su tipo de retorno.

**Cómo comprobarlo y resultado esperado:** Apollo Studio muestra la sección Mutation con createTodo.

**Procedencia:** E6 / E7.

## Fase 2 — Crear el InputType

**Objetivo:** Crear el InputType.

**Código o cambio acumulativo:**

```ts
import { Field, InputType } from '@nestjs/graphql';

@InputType()
export class CreateTodoInput {
  @Field(() => String, { description: 'What needs to be done' })
  description: string;
}
```


**Por qué:** El input es el equivalente al body de REST: un tipo con los campos que el cliente debe enviar.

**Cómo comprobarlo y resultado esperado:** El esquema incluye input CreateTodoInput { description: String! }.

**Procedencia:** E8 / E9 / E10.

## Fase 3 — Recibir el input como argumento

**Objetivo:** Recibir el input como argumento.

**Código o cambio acumulativo:**

```ts
@Mutation(() => Todo, { name: 'createTodo' })
createTodo(@Args('createTodoInput') createTodoInput: CreateTodoInput) {
  console.log({ createTodoInput });
  return null;
}
```


**Por qué:** El nombre de @Args es el que verá el cliente; el input llega como variable desde Apollo Studio.

**Cómo comprobarlo y resultado esperado:** mutation($createTodoInput: CreateTodoInput!) imprime el objeto en consola; la respuesta da error porque devuelve null.

**Procedencia:** E10 / E11 / E12.

## src/todo/todo.resolver.ts

Procedencia: E3, E5 (contexto), E6–E11.

```ts
import { Args, Int, Mutation, Query, Resolver } from '@nestjs/graphql';
import { CreateTodoInput } from './dto/inputs/create-todo.input';
import { Todo } from './entity/todo.entity';
import { TodoService } from './todo.service';

@Resolver()
export class TodoResolver {
  constructor(private readonly todoService: TodoService) {}

  @Query(() => [Todo], { name: 'todos' })
  findAll(): Todo[] {
    return this.todoService.findAll();
  }

  @Query(() => Todo, { name: 'todo' })
  findOne(@Args('id', { type: () => Int }) id: number): Todo {
    return this.todoService.findOne(id);
  }

  @Mutation(() => Todo, { name: 'createTodo' })
  createTodo(@Args('createTodoInput') createTodoInput: CreateTodoInput) {
    console.log({ createTodoInput });
    return null;
  }
}
```

# Resumen mental

Mutation + InputType + @Args(nombre) = body tipado de GraphQL. Las variables separan la consulta de los datos.
