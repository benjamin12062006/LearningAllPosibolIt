## Objetivo de la lección

Crear el recurso seed con una Mutation executeSeed sin argumentos que delega en SeedService, planificar los pasos (purgar, crear usuarios, crear items) y exportar TypeOrmModule en users e items.

## Estado inicial heredado

Anylist con auth, users e items; sin datos de prueba organizados.

## Fase 1 — Generar el recurso

**Objetivo:** Generar el recurso.

**Código o cambio acumulativo:**

```bash
nest g res seed --no-spec
# GraphQL (code first), sin CRUD
```


**Por qué:** El seed vive en su propio módulo, separado de users e items.

**Cómo comprobarlo y resultado esperado:** AppModule importa SeedModule.

**Procedencia:** E2 / E3.

## Fase 2 — Declarar la mutación

**Objetivo:** Declarar la mutación.

**Código o cambio acumulativo:**

```ts
import { Mutation, Resolver } from '@nestjs/graphql';
import { SeedService } from './seed.service';

@Resolver()
export class SeedResolver {
  constructor(private readonly seedService: SeedService) {}

  @Mutation(() => Boolean, { name: 'executeSeed', description: 'Ejecuta la construcción de la base de datos' })
  async executeSeed(): Promise<boolean> {
    return this.seedService.executeSeed();
  }
}
```


**Por qué:** Borrar e insertar son cambios de datos: Mutation, no Query.

**Cómo comprobarlo y resultado esperado:** mutation { executeSeed } devuelve true.

**Procedencia:** E1 / E4 / E5.
