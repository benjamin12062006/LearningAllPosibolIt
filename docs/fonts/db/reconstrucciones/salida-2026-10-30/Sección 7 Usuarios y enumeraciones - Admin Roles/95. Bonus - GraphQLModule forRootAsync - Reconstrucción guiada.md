## Objetivo de la lección

Configurar GraphQLModule con forRootAsync, importando AuthModule e inyectando JwtService en useFactory, para inspeccionar el token en context y poder bloquear el esquema a peticiones sin token.

## Estado inicial heredado

AppModule con GraphQLModule.forRoot (ApolloDriver, playground false, plugin de Apollo Studio, autoSchemaFile) y AuthModule que exporta JwtModule.

## Fase 1 — Pasar de forRoot a forRootAsync

**Objetivo:** Pasar de forRoot a forRootAsync.

**Código o cambio acumulativo:**

```ts
GraphQLModule.forRootAsync({
  driver: ApolloDriver,
  imports: [],
  inject: [],
  useFactory: async () => ({
    playground: false,
    autoSchemaFile: join(process.cwd(), 'src/schema.gql'),
    plugins: [ApolloServerPluginLandingPageLocalDefault],
  }),
}),
```


**Por qué:** El módulo asíncrono espera a otros módulos y permite inyectar servicios en su configuración.

**Cómo comprobarlo y resultado esperado:** La aplicación funciona igual que antes.

**Procedencia:** E2 / E3 / E4.

## Fase 2 — Leer el token en context

**Objetivo:** Leer el token en context.

**Código o cambio acumulativo:**

```ts
context({ req }) {
  const token = req.headers.authorization?.replace('Bearer ', '');
}
```


**Por qué:** context se ejecuta en cada operación (también en las consultas de introspección que hace Apollo Studio).

**Cómo comprobarlo y resultado esperado:** La consola imprime el token cuando se envía el header.

**Procedencia:** E5 / E6 / E7.

## Fase 3 — Inyectar JwtService y validar

**Objetivo:** Inyectar JwtService y validar.

**Código o cambio acumulativo:**

```ts
imports: [AuthModule],
inject: [JwtService],
useFactory: async (jwtService: JwtService) => ({
  // ...
  context({ req }) {
    const token = req.headers.authorization?.replace('Bearer ', '');
    if (!token) throw Error('Token needed');
    const payload = jwtService.decode(token);
    if (!payload) throw Error('Token not valid');
  },
}),
```


**Por qué:** Para usar un servicio de otro módulo hay que importarlo e inyectarlo explícitamente.

**Cómo comprobarlo y resultado esperado:** Sin token el esquema no carga ("Context creation failed: Token needed").

**Procedencia:** E8 / E9 / E10 / E11.

## Fase 4 — Desactivar el bloqueo

**Objetivo:** Desactivar el bloqueo.

**Código o cambio acumulativo:**

```ts
// Comentar las líneas del token dentro de context
```


**Por qué:** Bloquear todo el endpoint impide signup/login; el instructor recomienda separar esas operaciones (por ejemplo en REST).

**Cómo comprobarlo y resultado esperado:** Signup/login vuelven a funcionar sin token.

**Procedencia:** E1 / E12.

```ts
import { join } from 'path';
import { Module } from '@nestjs/common';
import { ConfigModule } from '@nestjs/config';
import { GraphQLModule } from '@nestjs/graphql';
import { JwtService } from '@nestjs/jwt';
import { ApolloDriver } from '@nestjs/apollo';
import { ApolloServerPluginLandingPageLocalDefault } from 'apollo-server-core';
import { AuthModule } from './auth/auth.module';
// ... resto de módulos (TypeORM, Items, Users) sin cambios

@Module({
  imports: [
    ConfigModule.forRoot(),

    GraphQLModule.forRootAsync({
      driver: ApolloDriver,
      imports: [AuthModule],
      inject: [JwtService],
      useFactory: async (jwtService: JwtService) => ({
        playground: false,
        autoSchemaFile: join(process.cwd(), 'src/schema.gql'),
        plugins: [ApolloServerPluginLandingPageLocalDefault],
        context({ req }) {
          // Bloqueo del esquema desactivado: signup y login también necesitarían token.
          // const token = req.headers.authorization?.replace('Bearer ', '');
          // if (!token) throw Error('Token needed');
          // const payload = jwtService.decode(token);
          // if (!payload) throw Error('Token not valid');
        },
      }),
    }),

    // GraphQLModule.forRoot<ApolloDriverConfig>({ ... }) // configuración síncrona anterior, comentada
    AuthModule,
  ],
})
export class AppModule {}
```

# Resumen mental

forRootAsync = forRoot + imports/inject/useFactory. context ve cada request y permite autenticar a nivel de esquema, pero bloquearía también las operaciones públicas.
