## Fase 2 — Crear cada producto con el servicio, en paralelo

**Objetivo:** Crear cada producto con el servicio, en paralelo.

**Código o cambio acumulativo:**

```ts
import { Injectable } from '@nestjs/common';
import { ProductsService } from '../products/products.service';
import { initialData } from './data/seed-data';

@Injectable()
export class SeedService {
  constructor(private readonly productsService: ProductsService) {}

  async runSeed() {
    await this.insertNewProducts();
    return 'SEED EXECUTED';
  }

  private async insertNewProducts() {
    await this.productsService.deleteAllProducts();

    const products = initialData.products;

    const insertPromises = [];

    products.forEach((product) => {
      insertPromises.push(this.productsService.create(product));
    });

    await Promise.all(insertPromises);

    return true;
  }
}
```


**Por qué:** Reutilizar create aplica el mismo procesamiento (slug, imágenes, validaciones) que la API.

**Cómo comprobarlo y resultado esperado:** GET /api/seed tarda menos de un segundo y crea productos con imágenes.

**Procedencia:** E4 / E5 / E6 / E7 / E8 / E9 / E10 / E11.
