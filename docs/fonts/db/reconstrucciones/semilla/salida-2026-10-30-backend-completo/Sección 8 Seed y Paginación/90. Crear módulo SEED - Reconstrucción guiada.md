## Objetivo de la lección

Crear en el proyecto Pokedex (MongoDB) un SeedModule con GET /api/v2/seed que delega en SeedService.executeSeed.

## Estado inicial heredado

Pokedex con prefijo global api/v2 y PokemonModule con su modelo de Mongoose (sección 7).

## Fase 1 — Generar y recortar el recurso

**Objetivo:** Generar y recortar el recurso.

**Código o cambio acumulativo:**

```bash
nest g res seed --no-spec
```


**Por qué:** Generar y eliminar lo sobrante es más rápido que escribirlo a mano.

**Cómo comprobarlo y resultado esperado:** AppModule importa SeedModule.

**Procedencia:** E4 / E5.

## Fase 2 — Controlador con un único GET

**Objetivo:** Controlador con un único GET.

**Código o cambio acumulativo:**

```ts
import { Controller, Get } from '@nestjs/common';
import { SeedService } from './seed.service';

@Controller('seed')
export class SeedController {
  constructor(private readonly seedService: SeedService) {}

  @Get()
  executeSeed() {
    return this.seedService.executeSeed();
  }
}
```


**Por qué:** Un solo disparador sin cuerpo.

**Cómo comprobarlo y resultado esperado:** GET http://localhost:3000/api/v2/seed responde.

**Procedencia:** E1 / E6 / E9.
