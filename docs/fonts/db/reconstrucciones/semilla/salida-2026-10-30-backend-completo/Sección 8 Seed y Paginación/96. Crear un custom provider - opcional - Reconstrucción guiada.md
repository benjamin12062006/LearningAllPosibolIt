## Objetivo de la lección

Sacar axios de SeedService con el patrón adaptador: interfaz HttpAdapter, AxiosAdapter inyectable en CommonModule y SeedService que depende del adaptador.

## Estado inicial heredado

SeedService usa axios directamente como propiedad (lecciones 92–95). CommonModule existe desde la sección anterior.

## Fase 1 — Definir el contrato

**Objetivo:** Definir el contrato.

**Código o cambio acumulativo:**

```ts
export interface HttpAdapter {
  get<T>(url: string): Promise<T>;
}
```


**Por qué:** Cualquier cliente HTTP futuro (fetch u otro) implementará este método.

**Cómo comprobarlo y resultado esperado:** Compila.

**Procedencia:** E2 / E3 / E4 / E5.

## Fase 2 — Implementar el adaptador de axios

**Objetivo:** Implementar el adaptador de axios.

**Código o cambio acumulativo:**

```ts
import { Injectable } from '@nestjs/common';
import axios, { AxiosInstance } from 'axios';
import { HttpAdapter } from '../interfaces/http-adapter.interface';

@Injectable()
export class AxiosAdapter implements HttpAdapter {
  private axios: AxiosInstance = axios;

  async get<T>(url: string): Promise<T> {
    try {
      const { data } = await this.axios.get<T>(url);
      return data;
    } catch (error) {
      throw new Error('This is an error - Check logs');
    }
  }
}
```


**Por qué:** Si axios cambia su API, solo se modifica esta clase.

**Cómo comprobarlo y resultado esperado:** Compila e implementa HttpAdapter.

**Procedencia:** E1 / E6 / E7 / E8 / E9 / E10.

**Procedencia:** E11 / E12 / E13.

## Fase 4 — Inyectar el adaptador en la semilla

**Objetivo:** Inyectar el adaptador en la semilla.

**Código o cambio acumulativo:**

```ts
import { Injectable } from '@nestjs/common';
import { InjectModel } from '@nestjs/mongoose';
import { Model } from 'mongoose';
import { AxiosAdapter } from '../common/adapters/axios.adapter';
import { Pokemon } from '../pokemon/entities/pokemon.entity';
import { PokeResponse } from './interfaces/poke-response.interface';

@Injectable()
export class SeedService {
  constructor(
    @InjectModel(Pokemon.name)
    private readonly pokemonModel: Model<Pokemon>,

    private readonly http: AxiosAdapter,
  ) {}

  async executeSeed() {
    await this.pokemonModel.deleteMany({}); // delete * from pokemons;

    const data = await this.http.get<PokeResponse>(
      'https://pokeapi.co/api/v2/pokemon?limit=650',
    );

    const pokemonToInsert: { name: string; no: number }[] = [];

    data.results.forEach(({ name, url }) => {
      const segments = url.split('/');
      const no: number = +segments[segments.length - 2];

      pokemonToInsert.push({ name, no });
    });

    await this.pokemonModel.insertMany(pokemonToInsert);

    return 'Seed Executed';
  }
}
```


**Por qué:** SeedService ya no conoce axios; solo el contrato del adaptador.

**Cómo comprobarlo y resultado esperado:** GET /api/v2/seed vuelve a cargar 650 pokémon con IDs nuevos.

**Procedencia:** E14.

# Resumen mental

La semilla depende de un proveedor propio inyectable, no de una librería de terceros; cambiar de cliente HTTP es crear otro adaptador.
