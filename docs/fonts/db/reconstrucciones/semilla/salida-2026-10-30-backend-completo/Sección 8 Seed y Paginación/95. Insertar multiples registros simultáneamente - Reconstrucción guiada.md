## Objetivo de la lección

Acelerar la semilla: borrar la colección antes de insertar, comparar Promise.all con insertMany y quedarse con una única inserción masiva de 650 registros.

## Fase 1 — Inserciones simultáneas con Promise.all

**Objetivo:** Inserciones simultáneas con Promise.all.

**Código o cambio acumulativo:**

```ts
const insertPromisesArray = [];

data.results.forEach(({ name, url }) => {
  const segments = url.split('/');
  const no: number = +segments[segments.length - 2];

  insertPromisesArray.push(this.pokemonModel.create({ name, no }));
});

await Promise.all(insertPromisesArray);
```


**Por qué:** Se dejan de esperar las inserciones una por una.

**Cómo comprobarlo y resultado esperado:** Falla con registros duplicados si ya había datos.

**Procedencia:** E1 / E2 / E3.

## Fase 2 — Purgar antes de sembrar

**Objetivo:** Purgar antes de sembrar.

**Código o cambio acumulativo:**

**Por qué:** Una semilla repetible debe partir de un estado conocido.

**Cómo comprobarlo y resultado esperado:** Ejecutar la semilla dos veces seguidas ya no falla.

## Fase 3 — Una sola inserción masiva

**Objetivo:** Una sola inserción masiva.

**Código o cambio acumulativo:**

```ts
import { Injectable } from '@nestjs/common';
import { InjectModel } from '@nestjs/mongoose';
import axios, { AxiosInstance } from 'axios';
import { Model } from 'mongoose';
import { Pokemon } from '../pokemon/entities/pokemon.entity';
import { PokeResponse } from './interfaces/poke-response.interface';

@Injectable()
export class SeedService {
  private readonly axios: AxiosInstance = axios;

  constructor(
    @InjectModel(Pokemon.name)
    private readonly pokemonModel: Model<Pokemon>,
  ) {}

  async executeSeed() {
    await this.pokemonModel.deleteMany({}); // delete * from pokemons;

    const { data } = await this.axios.get<PokeResponse>(
      'https://pokeapi.co/api/v2/pokemon?limit=650',
    );

    const pokemonToInsert: { name: string; no: number }[] = [];

    data.results.forEach(({ name, url }) => {
      const segments = url.split('/');
      const no: number = +segments[segments.length - 2];

      pokemonToInsert.push({ name, no }); // [{ name: bulbasaur, no: 1 }]
    });

    await this.pokemonModel.insertMany(pokemonToInsert);
    // insert into pokemons (name, no)
    // (name: bulbasaur, no: 1)
    // (name: ivysaur, no: 2)

    return 'Seed Executed';
  }
}
```


**Por qué:** insertMany manda todos los documentos en una única operación.

**Cómo comprobarlo y resultado esperado:** 650 documentos en la colección tras una petición.

**Procedencia:** E6 / E7 / E8 / E9 / E10.
