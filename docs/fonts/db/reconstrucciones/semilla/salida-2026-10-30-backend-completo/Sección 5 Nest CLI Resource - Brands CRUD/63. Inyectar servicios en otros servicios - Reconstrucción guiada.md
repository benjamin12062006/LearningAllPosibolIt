## Objetivo de la lección

Usar CarsService y BrandsService desde SeedService: exportar cada servicio en su módulo, importar esos módulos en SeedModule y documentar la semilla en el README.

## Estado inicial heredado

CARS_SEED, BRANDS_SEED y los métodos fill…WithSeedData existen (lección 62); SeedService aún no los usa.

## Fase 1 — Intentar inyectar sin exportar

**Objetivo:** Intentar inyectar sin exportar.

**Código o cambio acumulativo:**

```ts
constructor(private readonly carsService: CarsService) {}
```


**Por qué:** Muestra que un proveedor de otro módulo no es visible por defecto.

**Cómo comprobarlo y resultado esperado:** Nest falla con «can't resolve dependencies of the SeedService (?)».

**Procedencia:** E1 / E2 / E3.

## Fase 2 — Exportar el servicio e importar el módulo

**Objetivo:** Exportar el servicio e importar el módulo.

**Código o cambio acumulativo:**

```ts
@Module({
  controllers: [CarsController],
  providers: [CarsService],
  exports: [CarsService],
})
export class CarsModule {}


import { Module } from '@nestjs/common';
import { BrandsModule } from '../brands/brands.module';
import { CarsModule } from '../cars/cars.module';
import { SeedController } from './seed.controller';
import { SeedService } from './seed.service';

@Module({
  controllers: [SeedController],
  providers: [SeedService],
  imports: [CarsModule, BrandsModule],
})
export class SeedModule {}
```


**Por qué:** Solo lo que un módulo exporta es accesible fuera; se importa el módulo, no el servicio suelto.

**Cómo comprobarlo y resultado esperado:** La aplicación arranca y GET /seed carga los carros.

**Procedencia:** E4 / E5.

## Fase 3 — Repetir con las marcas

**Objetivo:** Repetir con las marcas.

**Código o cambio acumulativo:**

```ts
@Module({
  controllers: [BrandsController],
  providers: [BrandsService],
  exports: [BrandsService],
})
export class BrandsModule {}


import { Injectable } from '@nestjs/common';
import { BrandsService } from '../brands/brands.service';
import { CarsService } from '../cars/cars.service';
import { BRANDS_SEED } from './data/brands.seed';
import { CARS_SEED } from './data/cars.seed';

@Injectable()
export class SeedService {
  constructor(
    private readonly carsService: CarsService,
    private readonly brandsService: BrandsService,
  ) {}

  populateDB() {
    this.carsService.fillCarsWithSeedData(CARS_SEED);
    this.brandsService.fillBrandsWithSeedData(BRANDS_SEED);

    return 'SEED Executed';
  }
}
```


**Por qué:** Mismo mecanismo para BrandsService; ambos servicios comparten instancia singleton.

**Cómo comprobarlo y resultado esperado:** Tras GET /seed, GET /cars y GET /brands devuelven los datos de semilla.

**Procedencia:** E6 / E7 / E8.

# Resumen mental

Para usar un servicio ajeno: el módulo dueño lo exporta y el módulo consumidor importa ese módulo; la semilla orquesta servicios existentes.
